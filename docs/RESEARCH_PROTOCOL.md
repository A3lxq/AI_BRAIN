# ATHENA AI-BRAIN — Technology Research Protocol

Research is a formal engineering activity.

## Required process

1. Define the problem.
2. Identify viable alternatives.
3. Read primary documentation.
4. Inspect current ecosystem/tooling.
5. Evaluate Linux/Kali compatibility.
6. Evaluate security.
7. Evaluate maintainability.
8. Evaluate integration with ATHENA AI-BRAIN.
9. Prototype only when necessary.
10. Compare results.
11. Recommend one option.
12. Record the decision in an ADR.

## Minimum comparison criteria

- functionality
- maturity
- license
- ecosystem
- documentation
- Python/API support
- performance
- resource usage
- security
- observability
- testing
- deployment
- backup/recovery
- future migration cost

## Freshness

For rapidly changing technologies, research must use current official documentation.

Do not rely on stale model knowledge when the current behavior of a library, protocol, SDK, or API matters.
