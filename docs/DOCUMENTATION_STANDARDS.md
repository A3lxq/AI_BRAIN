# AI_BRAIN — Documentation Standards

## Markdown

Use:
- clear headings,
- concise sections,
- tables where useful,
- code fences for commands/code,
- links to primary sources,
- explicit assumptions.

## Research documents

Each research document should contain:

1. Executive summary
2. Problem being solved
3. Technology overview
4. Architecture
5. Alternatives
6. Comparison
7. AI_BRAIN relevance
8. Security
9. Performance
10. Operational concerns
11. Recommendation
12. References
13. Open questions

## ADRs

Each ADR contains:
- ID
- title
- status
- context
- decision
- alternatives
- rationale
- consequences
- references

## Session files

Each session records:
- objective,
- completed work,
- decisions,
- files changed,
- tests,
- unresolved issues,
- next steps.

## Accuracy

Do not present assumptions as facts.
Prefer primary documentation for technical claims.
Record the date of research for rapidly changing technologies.
