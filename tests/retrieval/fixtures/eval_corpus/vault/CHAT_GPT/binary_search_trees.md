# you asked

Explain what a binary search tree is and how lookup works.

# chatgpt response

A binary search tree (BST) is a hierarchical data structure where each node has at most two children. The left subtree contains only keys smaller than the node's key, and the right subtree contains only keys larger. Lookup starts at the root and recursively descends left or right depending on the comparison, giving O(log n) average-case time for a balanced tree.
