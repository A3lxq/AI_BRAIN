# you asked

What makes an API RESTful?

# chatgpt response

A RESTful API follows a set of architectural constraints: it is stateless (each request contains all information needed to process it), uses standard HTTP methods (GET, POST, PUT, DELETE) mapped to resource operations, addresses resources via URIs, and typically returns representations in JSON or XML. REST does not mandate a specific protocol beyond HTTP, but consistent use of status codes and idempotent methods (GET, PUT, DELETE) is expected.
